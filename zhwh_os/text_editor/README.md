# Text Editor - zhwh_os 轻量级文本编辑器

一个基于 LVGL 的 Sublime 风格轻量级文本编辑器，运行在 zhwh_os 操作系统上。

## 功能特性

### 基础功能
- ✅ 基本文本编辑（插入、删除、退格）
- ✅ 光标移动（方向键、Home/End）
- ✅ 文件加载和保存
- ✅ 键盘和鼠标操作
- ✅ 多行文本编辑
- ✅ 状态栏显示

### 查找和替换
- ✅ 查找文本
- ✅ 替换文本
- ✅ 查找面板

### 用户界面
- ✅ 菜单栏（Open/Save/Find）
- ✅ 编辑区域
- ✅ 状态栏
- ✅ 文件标签显示
- ✅ 深色主题（类似 Sublime）

## 文件结构

```
text_editor/
├── Makefile          # 编译配置
├── README.md         # 本文档
├── text_editor.c     # 主程序（LVGL UI）
└── text_editor.h     # 编辑器核心数据结构
```

## 编译和运行

### 编译编辑器

```bash
cd text_editor
make clean
make
```

### 集成到系统

1. 编译生成 `text_editor.elf`
2. 将其添加到 ISO 文件系统
3. 在 zhwh_os 中运行

## 键盘快捷键

| 按键组合 | 功能 |
|---------|------|
| Ctrl+S | 保存文件 |
| Ctrl+F | 打开查找面板 |
| Ctrl+O | 打开文件 |
| Escape | 关闭查找面板 |
| Arrow Keys | 移动光标 |
| Home | 移到行首 |
| End | 移到行尾 |
| Page Up | 向上翻页 |
| Page Down | 向下翻页 |

## 技术架构

### 基于 LVGL 的 UI

- 使用 `lv_textarea` 作为核心编辑组件
- 自定义键盘输入处理
- 鼠标点击定位光标

### 文件 I/O

- 使用 zhwh_os 的文件系统系统调用
- 支持 UTF-8 文本（基础）
- 最大 8MB 文件大小

## 设计理念

受 Sublime Text 启发的设计：
